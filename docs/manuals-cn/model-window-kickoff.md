# 模型窗口启动

可在 **设置 > 模型窗口启动** 中启动提供商的配额窗口，而不会创建聊天会话。

1. 添加启动计划并选择智能体配置和模型。
2. 设置窗口时长和安全缓冲。默认值为五小时加 60 秒。
3. 设置**下次启动时间**，可将首次或下一次请求延后到指定时间。
4. 可选配置企业微信群机器人密钥，并为计划选择该通知渠道。

到达计划时间时，Pi Cloud 只会将配置的探测提示词直接发送给模型，不会加载工具、技能或记忆，也不会持久化会话。请求成功后，下次时间从成功请求时间开始计算。失败信息会显示在设置中，并在一小时后重试。

调度器每十分钟检查一次。如果 Pi Cloud 重启时计划已经逾期，启动后只发送一次请求，不会补发所有错过的周期。

企业微信机器人密钥保存在仅限当前用户访问的 Pi Cloud 应用数据库中，API 不会返回密钥内容。
