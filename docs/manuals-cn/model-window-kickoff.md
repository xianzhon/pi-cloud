# 模型窗口启动

可在 **设置 > 模型窗口启动** 中自动启动提供商的配额窗口。

1. 添加启动计划并选择智能体配置和模型。
2. 设置启动会话使用的项目目录。该目录必须存在，且位于配置的允许根目录内。
3. 设置窗口时长和安全缓冲。默认值为五小时加 60 秒。
4. 设置**下次启动时间**，可将首次或下一次请求延后到指定时间。
5. 可选配置企业微信群机器人密钥，并为计划选择该通知渠道。

到达计划时间时，Pi Cloud 会通过所选项目目录中的命名持久化 Pi 会话发送配置的探测提示词，默认提示词为 `Ping`。该会话会禁用记忆。请求成功后，下次时间从成功请求时间开始计算。失败信息会显示在设置中，并在一小时后重试。

调度器每分钟检查一次。如果 Pi Cloud 重启时计划已经逾期，启动后只发送一次请求，不会补发所有错过的周期。

企业微信机器人密钥保存在仅限当前用户访问的 Pi Cloud 应用数据库中，API 不会返回密钥内容。
