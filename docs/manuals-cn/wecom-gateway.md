# 企业微信网关

企业微信网关通过自建应用将 Pi Cloud 接入企业成员。当前版本支持文本消息、图片消息、语音消息和斜杠命令。语音消息需要先配置 Pi Cloud 的语音转文本服务。

## 配置步骤

1. 打开[企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame#apps)，创建或选择一个自建应用，并记录企业 ID（Corp ID）、应用 Agent ID 和 Secret。
2. 在 Pi Cloud 中打开 **设置 > 网关 > 企业微信自建应用**，填写上述信息，以及用英文逗号分隔的成员 User ID 白名单。只有在所有可见该应用的成员都可以使用时，才填写 `*`。
3. 点击 **保存并生成回调配置**，复制页面显示的回调 URL、Token 和 EncodingAESKey。
4. 在自建应用管理页面中，进入 **功能 > 接收消息 > 设置 API 接收**，粘贴这三个回调配置值并保存。企业微信完成验证或推送回调后，Pi Cloud 状态会变为 **回调已验证**。
5. 如果企业微信要求可信 IP，请将 Pi Cloud 的出口服务器 IP 加入应用可信 IP 列表，然后点击 **测试连接**。

Pi Cloud 必须能通过公网 HTTPS 被企业微信访问。回调端点是 `/api/gateways/wecom/callback`；Pi Cloud 会先校验签名并进行 AES 解密，再处理消息。网关用户可以在 Pi Cloud 主机上运行 coding agent 的工具，因此默认拒绝访问：成员白名单留空时会拒绝所有成员。被拒绝的成员会收到包含其 User ID 的回复，便于管理员将其加入白名单。

网关使用 **网关默认值** 中配置的 Agent 配置、模型、技能组和允许的文件夹。在企业微信中发送 `/help` 可以查看 `/new`、`/status`、`/profile`、`/cwd` 和 `/skillset` 等命令。

收到语音消息后，Pi Cloud 会从企业微信下载 AMR 媒体，将其发送到已配置的 OpenAI 兼容语音转文本端点，并且只把转写结果发送给 coding agent。请按照[配置说明](configuration.md#语音输入)设置 `PI_CLOUD_STT_*` 环境变量。如果转写服务不可用或转写失败，网关会返回错误提示，而不会发送空白消息。

## 执行控制和任务查询

```text
/stop                         # 别名 /abort
/status
/task list
/task status <编号或唯一标题>
/task result <编号或唯一标题>
/task stop <编号或唯一标题>
```

- 这些 slash 控制命令不进入普通消息队列，当前对话执行中也能使用。`/status` 增加执行中/停止中/空闲、已用秒数、排队消息数。
- `/stop` 请求中断当前对话，取消此前排队的消息，保留历史，不影响独立任务。停止是协作式请求，外部工具或不响应取消的模型不保证立即终止；后续普通消息会等待当前执行真正结束。
- `/task list` 列出当前允许项目的所有任务及状态；自然语言“列出未开始的任务”仍只列待办。编号始终对应本聊天最近一次任务列表，重新列出会更新编号，服务重启后须重新列出。标题支持无歧义的部分匹配。
- `/task status` 区分任务持久化状态与实时执行状态。`started` 不代表仍在运行或执行成功，执行结束也不会自动标记任务为 `completed`。
- `/task result` 返回会话最近一条助手文本，不包含 thinking 或工具输出；长内容截断，可凭返回的会话 ID 在 WebUI 查看完整记录。重启后仍可读取持久化会话，但不会恢复执行或猜测执行成功。
- `/task stop` 只停止当前服务中由网关启动的任务；WebUI 或自动队列执行须到对应入口停止。重复请求安全，不删除记录、不标记完成；启动准备中的任务请稍后重试。
- 支持“小助理，查看任务 2 的状态 / 结果”和“小助理，停止任务 <标题>”。自然语言指令仍会排队，执行中需要即时控制请使用上面的 slash 命令。

## 自然语言管理指令

以“小助理”开头发送文本或现有语音转写指令，例如“小助理，帮我开一个新对话”“小助理，我现在在哪个项目？”或“小助理，把工作目录切到 pi-cloud”。可通过 `PI_CLOUD_GATEWAY_COMMAND_PREFIX` 修改前缀。

- 支持新建对话、查询状态、查看帮助、切换允许的工作目录、Profile 和技能集。每条消息只处理一个操作；切换配置会沿用现有逻辑重置会话。
- 使用网关配置的模型；未指定时使用当前 Profile 的默认模型（未设置默认模型时使用第一个可用模型）。这会产生独立的模型调用费用，不写入聊天历史，也不会给解析模型提供工具。
- 参数必须来自已配置的选项。指令有歧义、不支持或包含多个操作时不执行；请以指令前缀开头重新发送完整指令，不要只回复选项名称。
- 模型出错或超时时不执行，也不会转为普通聊天。原有 `/命令` 不经过模型，其他消息仍作为普通聊天。语音转写能力不变。

## 环境变量托管

推荐使用 UI 配置。对于集中管理的部署，可以设置 `PI_CLOUD_WECOM_CORP_ID`、`PI_CLOUD_WECOM_CORP_SECRET`、`PI_CLOUD_WECOM_AGENT_ID`、`PI_CLOUD_WECOM_CALLBACK_TOKEN`、`PI_CLOUD_WECOM_ENCODING_AES_KEY`，以及 `PI_CLOUD_WECOM_ALLOWED_USERS`（用英文逗号分隔的 User ID，或 `*`）。环境变量会覆盖 UI 中保存的配置，并使设置页面变为只读。具体格式见 `.env.example`。

应用 Secret、回调 Token 和 EncodingAESKey 都属于敏感凭据。通过 UI 保存的值会使用 Pi Cloud 凭据加密密钥加密后写入 SQLite。请限制对数据库、凭据密钥和环境变量文件的访问。
