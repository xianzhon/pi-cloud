# PDF 标注用户手册

Pi Cloud 支持在工作区编辑器中打开并标注 PDF 文件。标注会单独保存，因此编辑操作不会修改原始 PDF。

## 打开并标注 PDF

1. 从工作区文件树打开一个 `.pdf` 文件。
2. 从标注工具栏中选择工具。
3. 选择颜色和粗细，然后在当前页面上绘制或放置标注。
4. 再次选择当前工具，即可返回普通的 PDF 浏览模式。

标注工具栏提供以下功能：

- **画笔和高亮**：绘制自由笔画。
- **直线、箭头、矩形和椭圆**：绘制图形。
- **文字**：放置文字批注，或选择已有批注进行编辑。
- **移动**：重新放置已有标注。
- **橡皮擦**：删除橡皮擦接触到的标注。
- **撤销和重做**：在当前 PDF 打开期间，向前或向后恢复标注操作。
- **清除当前页**：删除当前页面上的全部标注。

按 `1` 到 `8` 可按工具栏顺序选择工具，按 `0` 可选择橡皮擦。工具栏支持拖动，也可聚焦拖动手柄后用方向键移动，还可以在水平和垂直布局之间切换。

标注使用相对于页面的坐标，因此缩放 PDF 后仍会与页面内容保持对齐。

## 页面颜色

使用 PDF 导航工具栏中的页面颜色选择器，可选择**原始**、**暖色**、**灰色**或**深色**。该设置会随 PDF 视图状态一起保存，并且只影响屏幕预览；原始 PDF 和导出的副本仍会保留原始颜色。

## 保存和状态

绘制、擦除、撤销、重做或清除页面后，标注会自动保存。标注工具栏末尾的固定状态图标表示：

- 正在保存时显示旋转图标。
- 最新更改保存成功后显示对勾。
- 保存失败时显示错误图标。

PDF 标注不需要使用单独的“保存”命令。

## 保存位置

Pi Cloud 会在 PDF 旁边写入一个 JSON 边车文件（sidecar file）：

```text
<PDF 所在目录>/.<PDF 文件名>.annotations.json
```

例如：

```text
/books/example.pdf
/books/.example.pdf.annotations.json
```

文件名前的 `.` 会让边车文件在 Pi Cloud 的默认文件树视图中隐藏。如需查看或管理该文件，请在文件树中启用**显示隐藏文件**。边车文件按 PDF 页码保存矢量笔画，原始的 `example.pdf` 文件不会发生变化。

旧版 Pi Cloud 创建的边车文件使用可见名称 `example.pdf.annotations.json`。为保持兼容，Pi Cloud 仍会读取这种文件；下一次修改标注后，标注会保存到新的隐藏文件中，随后可以手动删除旧文件。

边车文件是普通的工作区文件，与编辑器中的其他文件遵循相同的允许根目录和文件系统权限限制。Pi Cloud 必须拥有 PDF 所在目录的写入权限才能保存标注。

## 备份、移动或分享标注

备份、复制、移动、重命名或分享带标注的文档时，请始终同时处理 PDF 及其边车文件。Pi Cloud 根据文件名和所在位置匹配两者；只移动或重命名 PDF 不会自动处理对应的边车文件。

如需删除所有已保存的标注，请先显示隐藏文件，删除对应的 `.<PDF 文件名>.annotations.json` 边车文件，然后重新打开 PDF。

## 当前限制

- 标注仅由 Pi Cloud 显示，不会嵌入 PDF。
- 使用其他 PDF 阅读器打开原始 PDF 时，不会显示边车文件中的标注。
- 当前不支持将标注导出或合并到新的 PDF。
- 当前不支持将单个标注导出为其他标注格式。
