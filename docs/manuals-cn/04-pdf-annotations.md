# PDF 标注用户手册

Pi WebUI 支持在工作区编辑器中打开 PDF 文件并进行自由绘制。标注会单独保存，因此绘制操作不会修改原始 PDF。

## 打开并标注 PDF

1. 从工作区文件树打开一个 `.pdf` 文件。
2. 在标注工具栏中选择**画笔**按钮。
3. 选择画笔颜色和粗细，然后在当前页面上绘制。
4. 再次选择画笔按钮，即可返回普通的 PDF 浏览模式。

标注工具栏还提供以下功能：

- **橡皮擦**：删除橡皮擦接触到的笔画。
- **撤销和重做**：在当前 PDF 打开期间，向前或向后恢复标注操作。
- **清除当前页**：删除当前页面上的全部标注。

标注使用相对于页面的坐标，因此缩放 PDF 后仍会与页面内容保持对齐。

## 保存和状态

绘制、擦除、撤销、重做或清除页面后，标注会自动保存。标注工具栏末尾的固定状态图标表示：

- 正在保存时显示旋转图标。
- 最新更改保存成功后显示对勾。
- 保存失败时显示错误图标。

PDF 标注不需要使用单独的“保存”命令。

## 保存位置

Pi WebUI 会在 PDF 旁边写入一个 JSON 边车文件（sidecar file）：

```text
<PDF 所在目录>/.<PDF 文件名>.annotations.json
```

例如：

```text
/books/example.pdf
/books/.example.pdf.annotations.json
```

文件名前的 `.` 会让边车文件在 Pi WebUI 的默认文件树视图中隐藏。如需查看或管理该文件，请在文件树中启用**显示隐藏文件**。边车文件按 PDF 页码保存矢量笔画，原始的 `example.pdf` 文件不会发生变化。

旧版 Pi WebUI 创建的边车文件使用可见名称 `example.pdf.annotations.json`。为保持兼容，Pi WebUI 仍会读取这种文件；下一次修改标注后，标注会保存到新的隐藏文件中，随后可以手动删除旧文件。

边车文件是普通的工作区文件，与编辑器中的其他文件遵循相同的允许根目录和文件系统权限限制。Pi WebUI 必须拥有 PDF 所在目录的写入权限才能保存标注。

## 备份、移动或分享标注

备份、复制、移动、重命名或分享带标注的文档时，请始终同时处理 PDF 及其边车文件。Pi WebUI 根据文件名和所在位置匹配两者；只移动或重命名 PDF 不会自动处理对应的边车文件。

如需删除所有已保存的标注，请先显示隐藏文件，删除对应的 `.<PDF 文件名>.annotations.json` 边车文件，然后重新打开 PDF。

## 当前限制

- 标注仅由 Pi WebUI 显示，不会嵌入 PDF。
- 使用其他 PDF 阅读器打开原始 PDF 时，不会显示边车文件中的标注。
- 当前不支持将标注导出或合并到新的 PDF。
- 当前工具支持自由绘制，暂不支持文字批注、高亮或图形。
