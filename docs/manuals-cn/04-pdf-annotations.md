# PDF 和图片标注用户手册

Pi Cloud 支持在工作区编辑器中打开并标注 PDF 和图片文件。标注会单独保存，因此编辑操作不会修改原始文档。

## 打开并标注文档

1. 从工作区文件树打开 PDF 或受支持的图片文件。
2. 从标注工具栏中选择工具。
3. 选择颜色和粗细，然后在当前页面或图片上绘制或放置标注。
4. 再次选择当前工具，即可返回普通的文档浏览模式。

标注工具栏提供以下功能：

- **画笔和高亮**：绘制自由笔画。
- **直线、箭头、矩形和椭圆**：绘制图形。
- **文字**：放置文字批注，或选择已有批注进行编辑。
- **移动**：重新放置已有标注。
- **橡皮擦**：删除橡皮擦接触到的标注。
- **撤销和重做**：在当前 PDF 打开期间，向前或向后恢复标注操作。
- **清除当前页**：删除当前页面上的全部标注。

按 `1` 到 `8` 可按工具栏顺序选择工具，按 `0` 可选择橡皮擦。工具栏支持拖动，也可聚焦拖动手柄后用方向键移动，还可以在水平和垂直布局之间切换。

标注使用相对于文档的坐标，因此缩放 PDF 或图片后仍会与内容保持对齐。

查看图片时，可以按住 Ctrl 或 Command 并滚动鼠标滚轮，或使用双指捏合进行缩放；拖动可平移，双击可重置缩放。也可以使用导航工具栏调整缩放。

## PDF 页面颜色

查看 PDF 时，可以使用导航工具栏中的页面颜色选择器选择**原始**、**暖色**、**灰色**或**深色**。该设置会随 PDF 视图状态一起保存，并且只影响屏幕预览；原始 PDF 和导出的副本仍会保留原始颜色。

## 保存和状态

绘制、擦除、撤销、重做或清除页面后，标注会自动保存。标注工具栏末尾的固定状态图标表示：

- 正在保存时显示旋转图标。
- 最新更改保存成功后显示对勾。
- 保存失败时显示错误图标。

PDF 和图片标注不需要使用单独的“保存”命令。

## 保存位置

Pi Cloud 会将 PDF 和图片标注保存为独立的 JSON 标注文件，并存放在隐藏的 `.annotations` 子目录中：

```text
<文档所在目录>/.annotations/<文档文件名>.annotations.json
```

例如：

```text
/books/example.pdf
/books/.annotations/example.pdf.annotations.json
```

目录名前的 `.` 会让该目录在 Pi Cloud 的默认文件树视图中隐藏。如需查看或管理该目录，请在文件树中启用**显示隐藏文件**。标注文件按页保存矢量标注，原始文档不会发生变化。

为保持向后兼容，Pi Cloud 可以读取文档旁名为 `.<文档文件名>.annotations.json` 或 `<文档文件名>.annotations.json` 的旧标注文件。这些旧文件不会被修改；新的保存内容会写入 `.annotations` 目录，之后可以手动删除旧标注文件。

标注文件是普通的工作区文件，与编辑器中的其他文件遵循相同的允许根目录和文件系统权限限制。Pi Cloud 必须拥有文档所在目录的写入权限，才能创建 `.annotations` 并保存标注。

## 备份、移动或分享标注

备份、复制、移动、重命名或分享带标注的文档时，请始终同时处理原文档及 `.annotations` 目录中对应的标注文件。Pi Cloud 根据文件名和所在位置匹配两者；只移动或重命名原文档不会自动处理对应的标注文件。

如需删除所有已保存的标注，请先显示隐藏文件，删除对应的 `.annotations/<文档文件名>.annotations.json` 标注文件，然后重新打开文档。

## 导出带标注的副本

使用导航工具栏中的下载按钮可导出扁平化副本。PDF 文件会下载为 `<名称>-annotated.pdf`，图片会下载为 `<名称>-annotated.png`。原始文档和标注文件不会发生变化。

## 当前限制

- 导出扁平化副本之前，标注与原始文档仍是分开保存的。
- 使用其他查看器打开原始文档时，不会显示标注文件中的内容。
- 当前不支持将单个标注导出为其他标注格式。
